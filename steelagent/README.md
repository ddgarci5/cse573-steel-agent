# steelagent: deterministic AISC 360-22 (LRFD) tools for W-shape members

System A of the CSE 573 Group 13 project ("Agentic AI for Design of Steel Structural Members").

## Layout
- `steelagent/shapes.py`: loads W-shapes from `data/aisc-shapes-database-v16_0.xlsx` (place the free AISC file there)
- `steelagent/compression.py`: Chapter E (E3 flexural buckling, both axes; E7 slender elements)
- `steelagent/flexure.py`: Chapter F (F2 yielding + LTB, F3 flange local buckling) and G2.1 shear
- `steelagent/tension.py`: Chapter D (D2 yielding; rupture only when An and U are given)
- `steelagent/search.py`: exhaustive lightest-passing-section search
- `validation/`: independent checks against AISC Manual tables and AISC Design Examples v16.0

AISC Manual tables and Design Examples are copyrighted. They are used only as internal ground truth and are not redistributed.

(the table parsers expect the Manual excerpts at the path set in `validation/parse_tables.py`).
