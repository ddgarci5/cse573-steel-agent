# Structural steel evaluation source inventory

40 source entries across eight collections. Two Quimby entries group four lettered parts each. The two identical printings of Memphis 5.10-3 are listed once. This inventory contains source metadata and links. Open each source for the original wording and figures.

- **Capacity only** means the problem asks for resistance or maximum supported load, so demand is unnecessary.
- **LRFD course context** means the Memphis handout leaves the method implicit. See the [course notes and solution index](https://www.ce.memphis.edu/3131/notes/notes.html) and [16th-edition course reference](https://www.ce.memphis.edu/3131/notes/pdfs/What_is_CIVL_3131_s26.pdf).
- **Unverified** means the edition, diagram, or solution could not be verified as indicated.
- Existing Dataset C examples are excluded from the inventory. [Original AISC D.1](https://www.ce.memphis.edu/3131/notes/pdfs/design_examples_v16.0.pdf#page=21) is a reference for the two existing tension cases. E.1B is included with its overlap flagged.
- Texas A&M edition evidence is in the [COSC 421 syllabus](https://faculty-legacy.arch.tamu.edu/mhaque/cosc421/COSC%20421%20Syllabus.pdf) and [companion compression notes](https://faculty-legacy.arch.tamu.edu/mhaque/cosc421/LRFD%20Axially%20Loaded%20Compression%20Members.pdf).
